A program that draws a kraken bursting out of a bathtub — one image, made to excite make.fun's AI judge. A giant octopus erupts from a clawfoot tub in a tiny tiled bathroom: tentacles everywhere, water exploding, one huge amber eye staring out, and a rubber duck that has seen too much. Drawn procedurally, pixel by pixel, from code alone — no assets, no network, no image model.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
